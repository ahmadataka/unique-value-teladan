# Unique Value Teladan

Kumpulan aset materi `Unique Value` SMA Teladan yang sudah diproduksi untuk kelas X dan kelas XI.

## Isi

- `pdf/`
  - materi kelas X tentang Revolusi Industri 4.0
  - materi kelas X tentang Gen-AI
  - materi kelas XI tentang pengantar machine learning dan Teachable Machine
  - materi kelas XI tentang machine learning untuk pendidikan dan usulan untuk SMA Teladan Yogyakarta
- `presentations/`
  - versi PPT untuk materi kelas X tentang Gen-AI
- `scripts/`
  - script generator PDF dan PPTX yang terkait langsung dengan aset di repo ini

## Catatan

- Repo ini hanya berisi aset hasil produksi dan generator utamanya.
- File sementara QA, preview render, dan file inspeksi tidak disertakan.
